# USCCB foundational documents — index (Tier C)

A catalogue of the USCCB's [foundational documents of Catholic Social
Teaching](https://www.usccb.org/beliefs-and-teachings/what-we-believe/catholic-social-teaching/foundational-documents)
page (fetched 2026-08-08), for a future contributor picking up where this
pass stopped. **Not a citation source** — nothing below has been checked
against its primary text or used in `principles/` or `rubric/` beyond what
is explicitly marked ✅. See `ccc-citation-map.md` for what actually has:
Tier A (one encyclical per principle) and Tier B
(`../rubric/known-tensions.md`'s worked cases).

Both lists below preserve the USCCB page's own order (numbered, not
strictly chronological — that's how the source page presents them, so a
reader checking this catalogue against the live page can follow along).
✅ marks a document already cited somewhere in this project; everything
else is genuinely Tier C — uncited, unverified, listed only so a future
pass doesn't have to re-derive the list from the USCCB page.
